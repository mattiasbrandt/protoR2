Set up in the ISD Go app
  1. Calibrate the throttle first. Nothing else can be set until it is done.
  2. Running mode: Forward and Reverse. The default only brakes on the first reverse.
  3. Throttle curve: both ends at 100, not Novice. Novice caps the dome at 70%.
  4. BEC voltage: 5.0 V. Its centre wire stays off the board.
  5. Start force: high.
  6. Active brake: off.
